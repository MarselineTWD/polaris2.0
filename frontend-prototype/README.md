# POLARIS frontend prototype

Статический интерактивный прототип интерфейса сервиса проектирования спутниковой группировки.

## Запуск

Из корня проекта:

```powershell
python -m http.server 8080 --directory frontend-prototype
```

Затем открыть `http://localhost:8080`.

Все зависимости и текстуры находятся внутри папки прототипа, интернет для запуска не требуется.

Прототип использует демонстрационные данные и не подключён к расчётному API.

## Что можно проверить

- перетаскивание и масштабирование Земли;
- непрерывное движение спутников и вращение орбит;
- выбор спутника, терминала, шлюза или орбитальной плоскости прямо на 3D-сцене;
- добавление отказа кликом по спутнику и отображение причины разрыва маршрута;
- переключение очередей запуска, времени и скорости моделирования;
- загрузку и экспорт JSON-сценария `cosmo-A-1.0`;
- редактирование RAAN, фазирования и дальности ISL в разделе «Проект»;
- сравнение двух вариантов расчёта.

Повторяющиеся детали 48 спутников отрисовываются через GPU-инстансинг. Линии сети обновляются отдельно от движения аппаратов, поэтому интерфейс остаётся плавным и не пересоздаёт геометрию на каждом кадре.
